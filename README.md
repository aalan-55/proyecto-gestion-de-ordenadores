# Computer-Reservation-System

Sistema de gestión y reserva de ordenadores remotos diseñado para que los alumnos puedan reservar equipos para sus proyectos académicos.

---

## Español

### Descripción del Proyecto
Este proyecto es una plataforma full-stack desarrollada para facilitar el acceso y la gestión de ordenadores remotos. Permite a los estudiantes consultar la disponibilidad de los equipos y realizar reservas de forma sencilla para trabajar en sus proyectos.

### Tecnologías Utilizadas
* **Backend:** **Node.js** con **Fastify** para un rendimiento de alta velocidad y baja sobrecarga en las peticiones HTTP.
* **Base de Datos:** **MongoDB** para una gestión flexible y escalable del almacenamiento de datos de usuarios, ordenadores y reservas.
* **Frontend:** **Vite.js** para una interfaz rápida, moderna y reactiva.

---

## English

### Project Overview
This project is a full-stack platform designed to manage and streamline remote computer access for students. It enables users to check device availability and book remote machines for their academic projects.

### Tech Stack
* **Backend:** **Node.js** with **Fastify** for high-performance, low-overhead HTTP handling.
* **Database:** **MongoDB** for flexible and scalable storage of users, computers, and reservation records.
* **Frontend:** **Vite.js** for a fast, modern, and responsive user interface.
